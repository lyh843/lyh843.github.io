Modularity Optimization

Greedy
Modularity

从每个节点独立成团开始，每一步都选择能让模块度提升最多的社区对进行合并。 这是一个直观的凝聚式过程：先有许多小岛，再逐渐形成大陆。

01
策略
自底向上合并
目标
最大化模块度
参数
无需预设社区数

核心直觉

一个好的社区划分，应当让社区内部实际出现的边，比保持节点度数不变的随机网络中 “应该出现”的边更多。模块度正是在比较这两个量。

模块度公式

\[ Q = \frac{1}{2m}\sum_{i,j} \left(A_{ij}-\frac{k_i k_j}{2m}\right)\delta(c_i,c_j) \]

对社区合并进行贪心搜索，每轮保留使 \(\Delta Q\) 最大且为正的操作。

\(A_{ij}\)：邻接矩阵元素 \(k_i\)：节点 \(i\) 的度 \(m\)：网络边数 \(\delta\)：同社区指示函数

算法流程

  1. 每个节点初始化为独立社区。
  2. 枚举存在连边的候选社区对。
  3. 试合并并重新计算模块度。
  4. 接受提升最大的合并，直至无法继续改进。
greedy_modularity.py 
def greedy_modularity(graph):
    current_partition = [{node} for node in graph.nodes()]
    current_score = modularity(graph, current_partition)

    while True:
        community_of = {}
        for idx, community in enumerate(current_partition):
            for node in community:
                community_of[node] = idx

        # 只考虑有边相连的社区对
        candidate_pairs = set()
        for u, v in graph.edges():
            cu, cv = community_of[u], community_of[v]
            if cu != cv:
                candidate_pairs.add(tuple(sorted((cu, cv))))

        best_partition = None
        best_score = current_score

        for first, second in candidate_pairs:
            merged_partition = []
            for idx, community in enumerate(current_partition):
                if idx == first:
                    merged = current_partition[first] | current_partition[second]
                    merged_partition.append(set(merged))
                elif idx != second:
                    merged_partition.append(set(community))

            trial_score = modularity(graph, merged_partition)
            if trial_score > best_score + 1e-12:
                best_score = trial_score
                best_partition = merged_partition

        if best_partition is None:
            break

        current_partition = best_partition
        current_score = best_score

    return normalize_partition(current_partition)

Louvain
Method

Louvain 把模块度优化拆成两个交替阶段：节点在局部寻找更合适的社区， 随后将整个社区压缩为超节点。图在每一层都变得更小，结构也更清晰。

02
策略
局部移动 + 聚合
目标
多层次模块度优化
特点
高效、可扩展

两阶段循环

第一阶段逐个考察节点，把它移动到能够获得最大正模块度增益的邻居社区； 第二阶段把已形成的社区压缩成超节点，并在聚合图上重复同样过程。

节点移动的模块度增益

\[ \Delta Q = \left[\frac{\Sigma_{in}+2k_{i,in}}{2m} -\left(\frac{\Sigma_{tot}+k_i}{2m}\right)^2\right] - \left[\frac{\Sigma_{in}}{2m} -\left(\frac{\Sigma_{tot}}{2m}\right)^2 -\left(\frac{k_i}{2m}\right)^2\right] \]
\(\Sigma_{in}\)：社区内部边权 \(\Sigma_{tot}\)：社区关联总边权 \(k_i\)：节点加权度 \(k_{i,in}\)：节点到社区的边权

算法流程

  1. 每个节点独立成社区。
  2. 随机遍历节点，尝试移动到邻居社区。
  3. 保留带来最大正模块度增益的移动。
  4. 将社区压缩成超节点，进入下一层。
louvain.py · 核心逻辑 
def louvain_one_level(graph, rng, max_iter=50):
    labels = {node: idx for idx, node in enumerate(graph.nodes())}
    best_score = modularity(graph, label_dict_to_partition(labels))
    nodes = list(graph.nodes())

    for _ in range(max_iter):
        changed = False
        order = nodes[:]
        rng.shuffle(order)

        for node in order:
            current = labels[node]
            candidates = {labels[n] for n in graph.neighbors(node)}
            local_best, local_score = current, best_score

            for candidate in candidates:
                trial = dict(labels)
                trial[node] = candidate
                score = modularity(graph, label_dict_to_partition(trial))
                if score > local_score + 1e-12:
                    local_best, local_score = candidate, score

            if local_best != current:
                labels[node] = local_best
                best_score = local_score
                changed = True

        if not changed:
            break

    return label_dict_to_partition(labels)


def louvain(graph, seed=42, max_levels=8):
    rng = random.Random(seed)
    current_graph = graph.copy()
    nx.set_node_attributes(
        current_graph,
        {node: {node} for node in graph.nodes()},
        'members',
    )

    for _ in range(max_levels):
        partition = louvain_one_level(current_graph, rng)
        if len(partition) == current_graph.number_of_nodes():
            break
        current_graph = aggregate_graph(current_graph, partition)

    return recover_original_partition(current_graph)

Label
Propagation

没有全局目标函数，也不需要预设社区数。每个节点只听邻居的意见， 采用当前最流行的标签；局部共识不断扩散，最终自然形成社区。

03
策略
异步邻居投票
目标
局部标签一致
复杂度
接近线性

核心直觉

网络中的密集区域拥有更多内部连边，因此某个标签更容易在区域内部反复传播并成为主导； 稀疏的社区间连边则不容易改变这种局部共识。

标签更新规则

\[ c_i(t+1)=\arg\max_{\ell} \sum_{j\in N(i)}\mathbf{1}\!\left(c_j(t)=\ell\right) \]

若多个标签获得相同最高票数，则随机选择；异步更新会立即影响同一轮中的后续节点。

\(N(i)\)：节点 \(i\) 的邻居 \(\ell\)：候选标签 \(\mathbf{1}\)：示性函数 \(t\)：当前迭代轮次

算法流程

  1. 给每个节点分配唯一标签。
  2. 随机打乱节点更新顺序。
  3. 采用邻居中出现次数最多的标签。
  4. 重复更新，直到整轮没有标签变化。
label_propagation.py 
def label_propagation(graph, seed=42, max_iter=200):
    rng = random.Random(seed)
    nodes = list(graph.nodes())

    # 初始时每个节点拥有唯一标签
    labels = {
        node: idx
        for idx, node in enumerate(nodes)
    }

    for _ in range(max_iter):
        changed = False
        order = nodes[:]
        rng.shuffle(order)

        for node in order:
            neighbor_labels = Counter(
                labels[neighbor]
                for neighbor in graph.neighbors(node)
            )
            if not neighbor_labels:
                continue

            best_count = max(neighbor_labels.values())
            best_labels = [
                label
                for label, count in neighbor_labels.items()
                if count == best_count
            ]

            current = labels[node]
            if current in best_labels:
                next_label = current
            else:
                next_label = rng.choice(sorted(best_labels))

            if next_label != current:
                labels[node] = next_label
                changed = True

        if not changed:
            break

    return label_dict_to_partition(labels)

Fluid
Communities

把社区想象成在网络中流动的液体：它们会扩张、收缩并争夺节点。 社区越小密度越高，从而获得更强的竞争力，避免被大社区轻易吞没。

04
策略
密度加权传播
输入
预设社区数 k
约束
社区不消失

动态平衡

与普通标签传播不同，Fluid Communities 会用社区规模的倒数作为密度。 小社区权重大、大社区权重小，这种负反馈使多个社区可以长期共存。

密度与节点得分

\[ \rho(c)=\frac{1}{|c|}, \qquad S_i(c)=\sum_{j\in\{i\}\cup N(i)} \mathbf{1}(c_j=c)\rho(c) \] \[ c_i\leftarrow\arg\max_c S_i(c) \]
\(\rho(c)\)：社区密度 \(|c|\)：社区节点数 \(S_i(c)\)：节点对社区的局部得分 \(k\)：预先指定的社区数量

算法流程

  1. 随机选择 \(k\) 个种子节点建立社区。
  2. 根据当前规模计算各社区密度。
  3. 节点选择邻域密度得分最高的社区。
  4. 保护社区最后一个节点，迭代至稳定。
fluid_communities.py · 核心迭代 
def fluid_communities(graph, k, seed=42, max_iter=250):
    if not nx.is_connected(graph):
        raise ValueError('graph must be connected')

    rng = random.Random(seed)
    nodes = list(graph.nodes())
    membership = {node: None for node in nodes}

    # 仅初始化 k 个种子，其余节点等待社区扩张
    seed_nodes = rng.sample(nodes, k)
    for idx, node in enumerate(seed_nodes):
        membership[node] = idx

    for _ in range(max_iter):
        changed = False
        order = nodes[:]
        rng.shuffle(order)

        for node in order:
            sizes = Counter(
                c for c in membership.values()
                if c is not None
            )
            current = membership[node]
            protected = (
                current
                if current is not None and sizes[current] == 1
                else None
            )

            density = {c: 1.0 / size for c, size in sizes.items()}
            scores = defaultdict(float)

            for neighbor in [node, *graph.neighbors(node)]:
                community = membership[neighbor]
                if community is not None:
                    scores[community] += density[community]

            if not scores:
                continue

            best = max(scores.values())
            candidates = [
                c for c, score in scores.items()
                if abs(score - best) < 1e-12
            ]
            next_community = (
                current
                if current in candidates
                else rng.choice(sorted(candidates))
            )

            if next_community != current and protected is None:
                membership[node] = next_community
                changed = True

        if not changed:
            break

    return label_dict_to_partition(membership)

Girvan–
Newman

社区之间的桥接边往往承担大量最短路径。Girvan-Newman 反复找到这些“交通要道”并将其删除， 让网络从整体逐层裂解成结构清晰的社区。

05
策略
自顶向下分裂
依据
边介数中心性
输出
层次化社区结构

桥边假设

社区内部通常存在许多可替代路径，而跨社区连接较少。因此跨社区边会出现在大量节点对的 最短路径上，具有较高边介数，删除后最容易让图产生新的连通分量。

边介数中心性

\[ B(e)=\sum_{s\neq t} \frac{\sigma_{st}(e)}{\sigma_{st}} \]

每删除一条边后都必须重新计算边介数，因为网络中的最短路径已经发生改变。

\(\sigma_{st}\)：\(s\) 到 \(t\) 的最短路径数 \(\sigma_{st}(e)\)：经过边 \(e\) 的最短路径数 \(B(e)\)：边 \(e\) 的桥接程度 \(Q\)：用于选择最佳分裂层次

算法流程

  1. 计算图中所有边的边介数。
  2. 删除边介数最高的边。
  3. 重新计算介数，直到产生新的连通分量。
  4. 比较各分裂层的模块度并保留最佳划分。
girvan_newman.py · Brandes + 分裂 
def edge_betweenness_centrality(graph):
    betweenness = defaultdict(float)

    for source in graph.nodes():
        stack = []
        predecessors = {node: [] for node in graph.nodes()}
        sigma = dict.fromkeys(graph.nodes(), 0.0)
        sigma[source] = 1.0
        distance = dict.fromkeys(graph.nodes(), -1)
        distance[source] = 0

        queue = deque([source])
        while queue:
            vertex = queue.popleft()
            stack.append(vertex)
            for neighbor in graph.neighbors(vertex):
                if distance[neighbor] < 0:
                    queue.append(neighbor)
                    distance[neighbor] = distance[vertex] + 1
                if distance[neighbor] == distance[vertex] + 1:
                    sigma[neighbor] += sigma[vertex]
                    predecessors[neighbor].append(vertex)

        dependency = dict.fromkeys(graph.nodes(), 0.0)
        while stack:
            vertex = stack.pop()
            coefficient = (1.0 + dependency[vertex]) / sigma[vertex]
            for predecessor in predecessors[vertex]:
                contribution = sigma[predecessor] * coefficient
                edge = tuple(sorted((predecessor, vertex)))
                betweenness[edge] += contribution
                dependency[predecessor] += contribution

    return {edge: value / 2.0 for edge, value in betweenness.items()}


def girvan_newman_best(graph, max_groups=16):
    work_graph = graph.copy()
    best_partition = [set(graph.nodes())]
    best_score = modularity(graph, best_partition)

    while work_graph.number_of_edges() > 0:
        before = nx.number_connected_components(work_graph)

        while nx.number_connected_components(work_graph) == before:
            scores = edge_betweenness_centrality(work_graph)
            edge = max(scores, key=scores.get)
            work_graph.remove_edge(*edge)

        partition = list(map(set, nx.connected_components(work_graph)))
        if len(partition) > max_groups:
            break

        score = modularity(graph, partition)
        if score > best_score:
            best_score, best_partition = score, partition

    return normalize_partition(best_partition)
